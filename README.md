# 슬라이스 애니씽 한글판 (Slice Anything KO)

three.js 씬 안의 어떤 메시든 원하는 평면으로 몇 번이고 잘라낼 수 있는 1인칭 절단 데모입니다. 잘린 조각마다 닫힌 솔리드와 자체 Rapier 물리 바디가 생기고, 절단면에는 그 물체의 내부 재질이 그대로 드러납니다.

이 저장소는 Patch의 **Slice anything**([원작 페이지](https://patch.gg/blendi/slice-anything))을 한국어로 옮기고, 정적 호스팅에서도 쓸 수 있게 한글 설정 패널을 덧붙인 한글판입니다. 원작의 코드와 에셋, 라이선스 고지를 그대로 유지합니다.

**라이브 데모:** https://sigco3111.github.io/slice-anything-ko/

## 주요 특징

- **자유로운 절단**: 칼날이 스친 평면을 따라 어떤 물체든 잘립니다. 잘린 두 쪽은 서로 정확히 맞닿는 단면을 가집니다.
- **물리 기반 조각**: 모든 조각은 볼륨과 무게중심이 계산된 닫힌 솔리드로, convex hull 콜라이더와 Rapier 리지드 바디를 얻습니다. 기둥을 자르면 그루터기가 남고, 등불의 줄을 자르면 등불이 떨어집니다.
- **재질별 내부 단면**: 대리석의 결, 멜론의 씨, 기둥을 관통하는 고리까지, 내부는 잘리지 않은 원래 위치에서 읽는 솔리드 텍스처로 그려집니다. 대리석·돌·나무·대나무·멜론·오렌지·사과·금속 등이 들어 있습니다.
- **두 자루의 검**: 빠르고 가벼운 카타나와 느리지만 길고 무거운 롱소드.
- **1인칭 탐험**: 황금빛 마당을 걸어 다니며 벨 것을 찾습니다. 마우스 드래그가 곧 칼의 궤적입니다.

## 조작법

| 입력 | 동작 |
| --- | --- |
| 마우스 클릭 | 화면 잠금(둘러보기 시작) |
| 마우스 드래그 | 칼 휘두르기 (드래그 방향이 절단 방향) |
| 마우스 오른쪽 버튼 유지 | 조준(슬로우 모션) + 절단선 표시, 휠로 칼 각도 조정 |
| WASD / 방향키 | 이동 / 회전 |
| Shift | 달리기 |
| Space | 점프 |
| F | 과일 던지기 |
| R | 초기화 |
| 1 / 2 | 카타나 / 롱소드로 바꾸기 |
| H | 화면 표시(UI) 끄기/켜기 |

## 설정 패널 (한글판 추가)

원작은 Patch 페이지가 제공하는 컨트롤로 설정을 바꾸기 때문에 단독 배포본에는 설정 UI가 없었습니다. 한글판은 정적 호스팅에서도 같은 설정을 쓸 수 있도록 화면 왼쪽 위에 한글 설정 패널(`src/demo/panel.ts`)을 추가했습니다.

- **검**: 카타나 / 롱소드 선택
- **속도**: 시간이 흐르는 빠르기 (1보다 작으면 슬로우 모션)
- **절단선**: 칼날이 지나갈 선을 범위 안의 모든 물체에 표시
- **중력**: 잘린 조각이 떨어지는 힘 (1~20 m/s²)
- **프레임당 절단**: 한 프레임에 절단에 쓰는 시간 예산 (ms)
- **칼날 물림**: 칼날이 처음 닿은 물체에 순간 머무는 연출
- **화면 흔들림**: 칼날이 물릴 때의 화면 흔들림
- **초기화 / 과일 던지기** 버튼

Patch의 블록 페이지 안에서는 원래처럼 Patch의 컨트롤이 그대로 동작합니다(패널은 단독 실행일 때만 나타납니다).

## 한글화 내용

- 조작 안내, 로딩 진행 문구, WebGL 미지원 안내 등 화면의 모든 영어 문구를 한국어로 번역
- 설정 컬럼의 이름과 설명을 한국어로 번역 (`make-recipe.mjs`가 생성하는 `recipe.json` 기준)
- 단독 배포용 한글 설정 패널과 로딩 화면 진행 표시 추가
- 코드, 물리, 절단 로직 등 원작의 동작은 변경하지 않음

## 실행 및 빌드

```bash
npm install
npm run dev      # 개발 서버 (포트 5375)
npm run build    # dist/에 정적 빌드
npm run serve    # 빌드 결과 미리보기 (포트 5374)
```

배포본은 `docs/` 폴더의 정적 파일이며 GitHub Pages로 서비스됩니다. WebGPU를 지원하는 브라우저에서 가장 잘 동작하며, 없으면 WebGL 2로 대체됩니다(상대적으로 덜 검증된 경로입니다).

## 기술 스택과 구조

- **three.js 0.186.1** (`three/webgpu`): WebGPU 렌더러, 모든 재질이 노드 재질. 씬 패스 + 블룸으로 구성된 자체 `RenderPipeline` 사용
- **Rapier 0.19.3** (`@dimforge/rapier3d-compat`): 고정 1/120초 스텝의 물리. 0.21.0에서는 convex hull이 평지에서 안정되지 않는 문제가 있어 의도적으로 고정된 버전
- **Vite 8** 빌드, TypeScript
- `src/lib/`: 절단 라이브러리 6개 파일(약 1,900줄). `cut.ts`와 `solid.ts`는 three의 삼각측량만 필요로 해서 Node나 워커에서도 실행 가능
- `src/demo/`: 1인칭 데모 (칼, 마당, 재질, 이펙트)
- 절단은 프레임당 예산(`budgetMs`, 기본 5ms) 안에서 단계적으로 처리되어, 1.7만 삼각형의 흉상도 한 프레임에 20~50ms가 아니라 3프레임에 4~8ms로 잘립니다.
